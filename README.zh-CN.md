# XBone Studio

### 一体化 CT/MR 科研影像工作站

**影像浏览 · 分割编辑 · 三维重建 · 配准分析**

[English](README.md) · [学术主页](https://junfeng-geo.github.io/)

XBone Studio 是面向科研与教学的 Windows 影像工作站，将 CT/MR 可视化、分割编辑、三维重建与配准整合在一个交互工作空间中。软件围绕骨科影像研究流程开发，当前 AI 集成主要面向脊柱相关任务。

> **本仓库用于项目展示。** 目前仅公开软件介绍与功能说明，不提供源码、安装包、模型权重或患者数据。

## 核心功能

- **CT/MR 影像浏览：** 支持 NIfTI/DICOM 导入，轴状、冠状和矢状位联动查看，以及标签叠加。
- **分割编辑：** 提供三平面画笔与橡皮擦、物理半径控制、撤销与重做，以及编辑区域的实时表面预览。
- **三维交互：** 支持表面重建、三维区域标记及选定对象内部的 CT/MRI 灰度查看。
- **配准与融合查看：** 支持 CT/MR 配准与融合浏览、三点对应配准、ICP 表面配准及配准统计信息查看。
- **研究结果导出：** 支持 STL、PLY、VTP 等表面网格格式。

## 连贯的研究流程

1. 导入影像，通过联动切面检查数据。
2. 查看并修正分割标签。
3. 生成三维表面，检查结构与局部区域。
4. 完成对象对齐并检查配准结果。
5. 导出几何结果，用于后续研究。
